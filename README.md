# Digital Design Projects using Synopsys

This repository contains various CMOS-based digital logic design and simulation projects developed using Synopsys tools.

The repository includes the implementation and simulation of:

* NOT Gate
* AND Gate
* OR Gate
* NAND Gate
* NOR Gate
* EXOR Gate
* EXNOR Gate
* Half Adder
* Full Adder

Each project folder contains:

* CMOS schematic design
* Symbol creation
* Simulation waveform
* Testbench explanation
* VPULSE configuration details
* Working principle and output verification

---

# Tools Used

* Synopsys Custom Compiler
* Synopsys PrimeWave
* CMOS Technology Library
